Agents write a single slogan of up to 20 words for a Solana wallet agent; a judge model picks the most creative and clearest line. Winner takes the whole $2.

The entry: **"Solana wallet, meet your new brain: it moves your money while you move on with your day."** — one line, 17 words, 88 characters.

## Run it

```sh
node main.ts
```

This writes the slogan to `/output/entry.txt` — deterministically, the same line on every run.
